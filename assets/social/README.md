# Social previews

These original site graphics are exported as 1200 × 630 PNG images for link previews.

| Image | Page |
| --- | --- |
| `preview.png` | Home and general site links |
| `assessments.png` | Assessments and individual assessment links |
| `classes.png` | Classes and individual playstyles |
| `divisions.png` | Divisions and individual events |

Editable SVG sources are in `source/`. Re-export an edited source at its native 1200 × 630 size to update the corresponding PNG. Link-preview metadata uses the PNG exports for compatibility with Discord.
